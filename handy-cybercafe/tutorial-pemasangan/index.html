Tutorial Pemasangan
HandyCafe

Pasang Server di komputer kaunter, kemudian sambungkan Client pada komputer pelanggan melalui rangkaian setempat.

HandyCafe menggunakan satu pemasang; anda memilih peranan Server atau Client semasa pemasangan.

Muat turun HandyCafe rasmi ↗

Sebelum bermula

  • Sediakan satu PC utama di kaunter untuk Server.
  • Sediakan PC pelanggan untuk Client.
  • Pastikan semua komputer berada pada rangkaian setempat (LAN) yang sama.
  • Semak keperluan sistem dan gunakan akaun yang mempunyai kebenaran pentadbir.

1. Pasang Server pada komputer kaunter

  1. Jalankan pemasang HandyCafe yang dimuat turun daripada laman rasmi.
  2. Pada skrin What will this PC be?, pilih Server.
  3. Lengkapkan pemasangan dan buka HandyCafe Server.
  4. Ikuti First Setup Wizard untuk menyediakan akaun Admin dan tetapan awal. Simpan maklumat log masuk dengan selamat.
  5. Selepas dashboard dibuka, gunakan Connection Wizard untuk memaparkan kod sambungan Client.
Tip: Pasang Server pada satu komputer pengurusan utama sahaja, biasanya komputer kaunter.

2. Pasang Client pada komputer pelanggan

  1. Jalankan pemasang HandyCafe yang sama pada komputer pelanggan.
  2. Pilih Client pada skrin pemilihan peranan.
  3. Lengkapkan pemasangan dan buka HandyCafe Client.
  4. Pada Server, buka Connection Wizard melalui halaman Computers atau Settings → Clients → Network.
  5. Catat kod pairing enam digit yang dipaparkan.
  6. Pada Client, masukkan kod itu dalam ruangan Pairing code dan tekan Connect.
  7. Tunggu sehingga status menunjukkan Connected. Ulang untuk setiap PC pelanggan.
Tempoh kod: Kod pairing sah selama 30 minit. Jika tamat tempoh, jana kod baharu melalui Connection Wizard pada Server.

3. Uji sambungan

  • Pastikan Client muncul dalam halaman Computers pada Server.
  • Pastikan Client memaparkan skrin idle/lock screen.
  • Mulakan satu sesi ujian daripada Server, semak pemasa dan hentikan sesi.
  • Semak rekod sesi dan kadar harga sebelum operasi sebenar.

4. Penyelesaian masalah

  • Pastikan Server sedang berjalan dan kedua-dua PC berada pada rangkaian LAN yang sama.
  • Semak Windows Firewall. Port lalai: TCP 5001, 5002, 5003 dan UDP 5004. Pairing kod turut memerlukan UDP 45998 pada Server.
  • Jana semula kod jika ia tamat tempoh.
  • Jika pairing gagal, cuba carian rangkaian atau masukkan alamat IP Server dan Connection Key secara manual.
Keselamatan rangkaian: Benarkan port hanya pada rangkaian yang dipercayai dan ikut dokumentasi rasmi. Jangan dedahkan port pengurusan ke internet awam tanpa kawalan keselamatan yang sesuai.

5. Tetapkan kadar harga

Selepas Server dan Client bersambung, semak mata wang, kadar sejam, pelan harga dan jadual harga dalam Settings. Kadar RM3 sejam yang dipaparkan pada portal ini hanyalah contoh; pemilik premis menentukan kadar sebenar.
